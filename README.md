# 📖 Project Overview

DinePulse is an AI-powered Smart Restaurant Management Platform designed to help restaurants streamline operations while improving customer wellness through intelligent recommendations and analytics.

The platform combines restaurant management, customer health analysis, inventory monitoring, demand forecasting, AI-powered insights, and business analytics into a single modern dashboard.

Unlike traditional restaurant management systems, DinePulse leverages Artificial Intelligence to provide predictive insights, operational recommendations, and personalized meal health analysis.

---

# 🎯 Objectives

- Improve restaurant operational efficiency.
- Reduce food waste through inventory tracking.
- Provide AI-powered business insights.
- Offer nutritional analysis for customer meals.
- Detect allergens and provide dietary safety recommendations.
- Monitor restaurant health and operational performance.
- Predict demand using AI.
- Improve customer satisfaction.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/ninjaaaa18/DinePulse.git
```

Navigate to the project

```bash
cd dinepulse
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL

NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run the project

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
